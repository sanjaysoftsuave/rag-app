# Exporting your data — Northwind Cloud

> Synthetic sample document for rag-app's quick start. Not a real company's policy.

A CSV export contains at most 100,000 rows per file. Larger exports are split
automatically into several files, delivered together as one ZIP archive.

JSON exports are available through the API only, not from the dashboard.

Finished exports are kept for 7 days and then deleted; download them before
then or run the export again.
