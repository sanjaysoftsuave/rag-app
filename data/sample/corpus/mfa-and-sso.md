# Multi-factor authentication and single sign-on — Northwind Cloud

> Synthetic sample document for rag-app's quick start. Not a real company's policy.

SMS verification codes are valid for 5 minutes. Some mobile carriers block
automated short-code messages; if codes never arrive, switch to an
authenticator app under Security → Two-factor.

Every account receives 10 backup codes when multi-factor authentication is
turned on. Each backup code works exactly once.

Single sign-on with SAML is available on the Business plan and above. It is not
available on the Free or Pro plans.
